# JVM — Георгий Петросян

Отчёты: P01, P02, P03, P04, P05, P06, P07, P08, P09, P10, P11, P12, P13, P14, P15, P16, P17, P18, P19, P20, P21, P22, P23, P24.

В папке labs — Word-отчёты с изображениями и исходные протоколы. В project — исходный код, Gradle Wrapper, ресурсы и инструкции запуска.

Запуск: открыть терминал в project и выполнить `bash gradlew run`. Требования к Java и команды проверки указаны в project/README.md. При первом запуске Gradle требуется загрузка зависимостей.

Снимки P05–P08 и P13 пересняты на работающем JavaFX. P24 содержит снимки добавления, фильтра, расчёта времени и ошибочного ввода. Изображения 04-evidence-viewer.png — снимки просмотра сохранённых протоколов, а не новый запуск всех прошлых практик.

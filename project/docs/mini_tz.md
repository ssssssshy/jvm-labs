# Краткое техническое задание

## Назначение

Создать учебное настольное приложение для ведения личного журнала тренировок.

## Данные тренировки

- дата;
- тип тренировки;
- длительность в минутах;
- уровень нагрузки;
- количество упражнений;
- комментарий.

## Проверяемые сценарии первой версии

1. Пользователь добавляет тренировку с обязательной датой и положительной длительностью.
2. Пользователь изменяет ранее сохранённую запись.
3. Пользователь удаляет выбранную запись после подтверждения.
4. Пользователь просматривает историю и фильтрует её по заданным параметрам.
5. Пользователь выбирает период и получает суммарную длительность тренировок.

## Предметные правила

- дата обязательна;
- длительность должна быть больше нуля;
- уровень нагрузки должен находиться в допустимом диапазоне;
- количество упражнений не может быть отрицательным.

## Не входит в первую версию

1. Авторизация и роли пользователей.
2. Облачная синхронизация между устройствами.
3. Интеграция с фитнес-браслетами и внешними сервисами.

## Критерий результата P01

Консольная программа запускается через Gradle Wrapper и выводит название проекта,
роль пользователя и решаемую проблему. Неверное имя класса приводит только к
диагностируемой ошибке запуска и не изменяет исходные данные.

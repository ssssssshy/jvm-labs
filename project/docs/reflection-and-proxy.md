# Аннотации и наблюдение за сервисом

## Операции

| Метод | Метаданные | Учёт Proxy |
|---|---|---|
| `create` | «Добавить тренировку» | да |
| `changeStatus` | «Изменить состояние тренировки» | да |
| `findAll` | аннотации нет | нет |
| `remove` | анотации нет | нет |

`OperationCatalog` читает только публичные методы и фильтрует их по `OperationTitle`. Значение
аннотации доступно во время выполнения из-за `RetentionPolicy.RUNTIME`. Аналогичная аннотация с
`RetentionPolicy.CLASS` сохраняется в class-файле, но `getAnnotation` её не возвращает.

## Границы посредника

`MonitoringProxy` увеличивает счётчик перед вызовом аннотированной операции и передаёт
управление целевому `WorkoutService`. Он не меняет аргументы, результат и предметные правила.
`equals`, `hashCode` и `toString` обслуживаются отдельно и не входят в метрику.

`Method.invoke` заворачивает ошибку целевого метода в `InvocationTargetException`. Посредник выбрасывает
`getCause()`, чтобы клиент получил тот же `IllegalArgumentException` с тем же сообщением, что и при прямом
вызове. Аннотация описывает операцию, но не заменяет проверки `WorkoutService`.

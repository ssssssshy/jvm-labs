# Паспорт учебного выпуска 1.0.0

## Итог

Версия 1.0.0 трекера тренировок принята на Linux x86_64. Сборка и 26 тестов
завершились успешно. Linux app-image запущен первый раз, повторно и при
`PATH=/nonexistent`; конфигурация, SQLite и журнал созданы вне каталога программы.

## Исправленный дефект

При сверке обнаружено, что интерфейс не реализовывал обещанные мини-ТЗ
длительность, фильтрацию и сумму за период. В модель и SQLite-схему добавлена
положительная длительность, в интерфейс — фильтр и расчёт, а в БД — миграция V003.
После исправления повторены все тесты и основной JavaFX-маршрут.

## Известные ограничения

- app-image собран и проверен только для Linux x86_64;
- независимая передача другому студенту не выполнялась; вместо неё проведён
  запуск из чистого пользовательского каталога по опубликованной инструкции;
- удаление выполняется явной кнопкой, но отдельный диалог подтверждения пока отсутствует;
- авторизация, облачная синхронизация и интеграция с устройствами не входят в версию 1.0.0;
- runtime содержит полную JDK из-за ограничения `jlink` в используемой сборке OpenJDK.

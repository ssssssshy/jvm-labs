# Граф сцены P05

Интерфейс строится контейнерами и не использует абсолютные координаты. Данные
хранятся в `ObservableList` внутри представления и после закрытия приложения
теряются; базы данных на этом этапе нет.

```text
Stage «Трекер тренировок»
└── Scene
    └── VBox root — вертикальная компоновка всего окна
        ├── Label — заголовок приложения
        ├── Label — связанный счётчик записей
        ├── TableView<Workout> — таблица записей
        │   ├── TableColumn ID
        │   ├── TableColumn Тип тренировки
        │   ├── TableColumn Дата
        │   └── TableColumn Состояние
        ├── HBox form — строка ввода
        │   ├── TextField — тип новой тренировки
        │   ├── Button — добавление записи
        │   ├── Button — замена состояния выбранной записи
        │   └── Button — удаление выбранной записи
        └── Label — подтверждение или объяснение ошибки
```

`VBox.setVgrow(table, Priority.ALWAYS)` позволяет таблице занимать свободную
высоту, а `HBox.setHgrow(typeField, Priority.ALWAYS)` растягивает поле ввода.
Поэтому после изменения размера окна элементы остаются доступны.

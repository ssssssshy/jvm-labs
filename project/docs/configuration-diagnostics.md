# Настройки и безопасная диагностика

Приложение читает параметры среды из `config/application.properties`. Путь можно
переопределить системным свойством `workout.config`, поэтому для другой машины не
требуется перекомпиляция.

| Параметр | Назначение | Проверка |
|---|---|---|
| `database.path` | Файл SQLite | Обязательный корректный путь |
| `service.url` | Адрес справочника | Абсолютный URL с `http` или `https` |
| `request.timeout.seconds` | Максимальное ожидание | Целое число от 1 до 30 |
| `log.level` | Минимальный уровень журнала | `DEBUG`, `INFO`, `WARNING` или `ERROR` |
| `log.directory` | Каталог файлов журнала | Обязательный корректный путь |

Относительные пути разрешаются от каталога файла настроек. Значения проверяются
до создания окна и сетевого запроса; сообщение называет конкретный параметр и
допустимый формат.

## Политика журнала

Каждая запись содержит версию приложения, уровень, событие, исход и UUID операции.
Для базы сохраняется только имя файла, для сервиса — только имя хоста. Журнал
ограничен тремя файлами примерно по 8 КиБ.

Запрещено журналировать:

- токены, пароли и ключи;
- тела HTTP-запросов и ответов;
- типы тренировок, комментарии и другие пользовательские значения;
- полные строки конфигурации;
- текст исключения, который может содержать входные данные.

При отказе сохраняется тип исключения, но не его сообщение. Этого достаточно,
чтобы связать этап и причину, не копируя потенциально чувствительные значения.

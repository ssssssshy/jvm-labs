# Соответствие FXML и контроллера P07

Разметка, оформление и обработчики разделены. `DesktopApp` находит FXML и CSS
через classpath, поэтому запуск не зависит от рабочего каталога или дерева
`src/main/resources` после упаковки.

| Элемент формы | fx:id | Поле контроллера | Назначение |
|---|---|---|---|
| Таблица | `workoutTable` | `TableView<Workout>` | Наблюдаемый список тренировок |
| Тип | `typeField` | `TextField` | Обязательный тип тренировки |
| Дата | `dateField` | `DatePicker` | Дата тренировки |
| Состояние | `statusField` | `ComboBox<WorkoutStatus>` | Состояние новой или выбранной записи |
| Добавить | `addButton` | `Button` | Вызывает `handleAdd` |
| Изменить | `changeStatusButton` | `Button` | Вызывает `handleChangeStatus` |
| Удалить | `removeButton` | `Button` | Вызывает `handleRemove` |
| Счётчик | `countLabel` | `Label` | Связан с размером списка |
| Сообщение | `messageLabel` | `Label` | Показывает результат действия |

Изменение цветов, отступов, размеров шрифта и минимальных размеров элементов в
CSS не требует изменений предметных классов `Workout` и `WorkoutStatus`.

Повреждённый `fx:id` разрывает связь с полем контроллера. Автоматическая проверка
создаёт изменённую копию разметки в памяти, получает `LoadException`, затем
загружает исходный ресурс без изменения файла проекта.

# Передача выпуска 1.0.0

## Запуск готового комплекта

Откройте каталог `WorkoutTracker` и выполните:

```bash
./bin/WorkoutTracker
```

Устанавливать Java и Gradle для готового комплекта не требуется. При первом
запуске приложение создаёт конфигурацию, SQLite и журнал в
`~/.workout-tracker`. Для изолированной проверки используйте:

```bash
WORKOUT_HOME=/tmp/workout-check ./bin/WorkoutTracker --smoke-test
```

Ожидаемый результат — строка `SMOKE_OK`, где `fxml=jar`. Повторный запуск должен
показать тот же путь к базе и сохранённое число записей.

## Проверка исходников

Для сборки нужны JDK 25, команды `java`, `javac` и доступ к зависимостям при
первом запуске:

```bash
./gradlew clean test packageAppImage
```

Успех подтверждается строкой `BUILD SUCCESSFUL`. Готовый каталог находится в
`build/package/WorkoutTracker`.

## Пользовательские данные

Не помещайте рабочую базу внутрь app-image. Для учебной демонстрации задавайте
отдельный `WORKOUT_HOME`. Восстановление резервной копии выполняйте только в
новый тестовый путь, не поверх рабочей базы.

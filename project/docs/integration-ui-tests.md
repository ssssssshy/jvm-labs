# Интеграционные и интерфейсные проверки

Практика P18 закрепляет один сквозной маршрут без обращения к рабочей базе
пользователя. Тест создаёт SQLite в `@TempDir`, передаёт репозиторий прикладному
сервису, а сервис — контроллеру через фабрику `FXMLLoader`.

| Граница | Проверка | Доказательство |
|---|---|---|
| Ресурсы | `main-view.fxml` и `style.css` доступны в classpath, FXML загружается | `fxmlAndCssResourcesLoadFromClasspath` |
| Пользовательский сценарий | Поля формы заполняются, кнопка добавления вызывается | Таблица получает ровно одну новую строку и показывает сообщение |
| Сквозное сохранение | Контроллер работает с временной SQLite через сервис | После повторного открытия базы введённая тренировка найдена |
| Хранилище | Схема и rollback выполняются настоящим JDBC | `SqliteWorkoutRepositoryTest` |

Действия с элементами JavaFX выполняются на JavaFX Application Thread. Тест ждёт
завершения через `FutureTask`, а не через фиксированный `sleep`. Каждый метод
получает новый временный каталог и новую фикстуру, поэтому не зависит от порядка.

Рабочий файл `data/workouts.db` тестами не используется и не изменяется.

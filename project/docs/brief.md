# Краткое описание проекта

## Проблема и пользователь

Пользователь регулярно тренируется и хочет видеть достоверную историю занятий.
Без специального приложения записи оказываются в заметках, таблицах или памяти,
из-за чего сложно оценить регулярность и суммарную продолжительность тренировок.

## Наблюдения о работе без приложения

1. Записи о тренировках хранятся в разных местах и имеют разный формат.
2. Ошибочная длительность или пропущенная дата обнаруживаются только при ручном просмотре.
3. Для подсчёта времени за период приходится повторно просматривать все записи.

## Первая ценность

Первая версия объединяет историю в локальном приложении, проверяет базовые поля и
позволяет получить суммарное время тренировок за период. На P01 реализован только
консольный запуск, который фиксирует тему, роль пользователя и решаемую проблему.

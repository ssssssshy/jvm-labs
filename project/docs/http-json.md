# HTTP и JSON справочника тренировок

Запрос: `GET http://127.0.0.1:<port>/directory`. Тайм-аут подключения — 2 секунды, запроса — 3 секунды.
Ответ — JSON-массив объектов с обязательными `code`, `name` и положительным целым `recommendedMinutes`.

```json
[
  {"code":"WT-RUN","name":"Бег","recommendedMinutes":30},
  {"code":"WT-YOGA","name":"Йога","recommendedMinutes":45}
]
```

`WorkoutTypeDirectoryClient` сначала проверяет диапазон HTTP 2xx, затем структуру JSON и все поля.
`WorkoutTypeDirectory` заменяет подтверждённый список только после проверки всего набора. HTTP 500 нельзя
разбирать как успех: тело ошибки не обязано соответствовать контракту успешных данных.

Скрытую ошибку мог бы вызвать объект с отсутствующим полем в середине массива: поэтому DTO всего
набора создаются до публикации. Запрос не должен выполняться в JavaFX Application Thread; при подключении
к UI его нужно запускать через фоновую задачу P13.

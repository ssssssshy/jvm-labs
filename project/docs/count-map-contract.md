# Контракт CountMap

`CountMap<T>` хранит количество добавлений каждого ключа. Для трекера тренировок
используется `CountMap<String>`, где ключом служит тип тренировки.

## Выбор коллекций

- `List` сохраняет порядок и все повторения, но для подсчёта требуется отдельный проход.
- `Set` хранит только уникальные значения и потерял бы число повторений.
- `Map` связывает каждый уникальный тип тренировки с его количеством.

## Методы

| Метод | Контракт |
|---|---|
| `add(T)` | Увеличивает количество на единицу; `null` запрещён |
| `getCount(T)` | Возвращает количество или `0` для отсутствующего ключа |
| `remove(T)` | Удаляет ключ и возвращает прежнее количество; для отсутствующего ключа возвращает `0` |
| `addAll(CountMap<? extends T>)` | Добавляет количества из источника, не изменяя источник |
| `toMap()` | Возвращает отдельный неизменяемый снимок |
| `copyTo(Map<? super T, Integer>)` | Копирует текущие количества в карту-приёмник |

`toMap` не возвращает внутренний `HashMap`, потому что вызывающий код смог бы
изменить количества в обход методов и нарушить запрет `null`. Отдельная копия
также не меняется после последующих операций с исходным счётчиком.

# Наблюдаемые данные и привязки P06

Единственный источник истины для таблицы и счётчика — `ObservableList<Workout>`.
`TableView` читает тот же список, а текст метки вычисляется привязкой
`Bindings.size(workouts)`. Обработчики не увеличивают и не уменьшают число вручную.

## Способы обновления

| Способ | Недостаток | Решение P06 |
|---|---|---|
| Повторно заполнить всю таблицу | Лишняя работа и риск потерять выбор | Не используется; список уведомляет таблицу |
| Вручную менять текст счётчика | Появляется вторая копия состояния | Не используется; текст связан с размером списка |
| Привязать свойства к данным | Значение всегда вычисляется из источника | Используется для счётчика и доступности действий |

## Замена неизменяемой записи

`Workout` является `record`, поэтому состояние не изменяется внутри существующего
объекта. Выбранная запись заменяется в `ObservableList` результатом `withStatus`.
Событие замены уведомляет `TableView`, и новое состояние появляется без `refresh`.

Обычный `ArrayList` не посылает уведомления JavaFX. Если изменить отдельный
`ArrayList`, связанная с `ObservableList` таблица ничего об этом не узнает.

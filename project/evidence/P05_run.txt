Практика P05 — протокол проверки
Дата проверки: 2026-10-04

Ожидания до запуска

- при первом запуске отображается одна начальная тренировка;
- одно нажатие с корректным типом добавляет ровно одну строку;
- пустое поле не меняет число строк и показывает способ исправления;
- после изменения размера элементы остаются видимыми;
- корректный повторный ввод снова добавляет одну строку.

Автоматический сценарий

$ ./gradlew clean runP05Check
[OK] при первом запуске одна строка: 1
[OK] одно нажатие добавляет одну строку: 2
[OK] поле очищается после успеха:
[OK] пустой ввод не меняет таблицу: 2
[OK] ошибка объясняет исправление: true
[OK] повторный корректный ввод добавлен: 3
[OK] снимок сохранён: ../labs/P05/screenshots/success.png
Все проверки P05 пройдены.

BUILD SUCCESSFUL in 5s

Обычный запуск

$ ./gradlew run
> Task :run

Окно открылось на текущем дисплее. После подтверждения запуска процесс остановлен
вручную, потому что обычное JavaFX-приложение работает до закрытия окна.

Примечание: проверочный launcher выводит предупреждение JavaFX о загрузке классов
из unnamed module. Оно не повлияло на запуск, проверки или создание снимка.
